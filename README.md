# Inventory List Analyzer

## 📦 Project Description

**Inventory List Analyzer** is a simple Python program that allows the user to enter inventory items, their categories, and quantities.

The program then creates an inventory summary and provides useful information such as total quantity, average quantity, minimum and maximum stock, sorted items, categories, and search results.

## 🎯 Features

* Add multiple inventory items
* Store item names and categories
* Store item quantities
* Calculate total quantity
* Calculate average quantity
* Find minimum quantity
* Find maximum quantity
* Find most stocked item
* Find least stocked item
* Display unique categories
* Sort items by quantity
* Display categories alphabetically
* Search for an item or category

## 🛠️ Requirements

* Python 3.x
* No external libraries are required

## ▶️ How to Run

1. Install Python 3.
2. Save the program as:

```text
inventory.py
```

3. Open the terminal or command prompt.
4. Run:

```text
python inventory.py
```

## 📝 How It Works

First, the program asks the user to enter:

* Item name
* Category
* Quantity

The entered information is stored in lists, sets, and dictionaries.

After entering all items, the program displays the inventory summary.

## 📊 Inventory Summary

The program calculates:

* Total different items
* Total quantity in stock
* Average quantity
* Minimum quantity
* Maximum quantity
* Most stocked item
* Least stocked item

## 🔍 Search

At the end, the user can search for an **item name or category**.

For example:

```text
Search item or category: pen
```

The program will display matching items.
